# Power tab

Integrated the owner-edited electrical SVG as a dark Power page. The measured
housing silhouette, feed positions, connected-node wire colours and equipment
icons remain authored SVG geometry. Added the membrane heater PSU/controller.

Power and plug annotations are separate. Power on implies plugged; unplugging
clears power and ULVAC filament state. Only the two ULVAC controllers have a
filament toggle; SingleGauge has power and plug controls. ULVAC toggles align
below the device icons. Controls work by mouse and keyboard.

Save records one attributed snapshot in an external power_snapshots.jsonl;
Discard restores the loaded state. Missing annotations remain unrecorded.
Stale writes and impossible powered/unplugged states are rejected. These
controls annotate the diagram and send no hardware commands.

Validation: 171 pytest tests passed; JavaScript syntax check and eight History
Node tests passed. Scratch Lab preview at port 48938, external runtime and
test operator. Browser checks covered navigation, back/forward, reload,
snapshot save/discard, power/plug/filament dependencies, both phone drawers,
390px document containment and aligned rails at 1280x700. No console errors.
Preview saved locally as local/power-webui.png. Version 0.25.2 invalidates
older immutable static assets.

Manual PSU readings and windowed Kikusui averages remain future Power work;
this release establishes the diagram and saved equipment annotations.
